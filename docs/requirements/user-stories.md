# User Stories

## Admin

### Create User

As an admin  
I want to create users  
So that I can manage access.

Acceptance Criteria:

- メール必須
- 重複不可
- 成功時一覧に表示

---

### Delete User

As an admin  
I want to delete users  
So that inactive users are removed.

Acceptance Criteria:

- 確認ダイアログあり
- 成功後一覧更新
